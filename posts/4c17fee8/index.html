时间序列诊断：自相关、平稳性与波动聚集

时间序列诊断：收益有没有时间结构？

前面的分析大多是在看“整体结果”：

  • 收益有没有增强？
  • 回撤有没有改善？
  • VaR / CVaR 有没有下降？
  • Alpha 是否显著？
  • Bootstrap 后结论稳不稳？
  • 参数选择有没有挖掘风险？

时间序列诊断问的是另一个问题：

每日收益按时间顺序排列以后，里面有没有可观察的时间结构？

这一步不是重新调参，也不是重新选 MA window。

它只是基于已经生成的样本外每日收益和回归残差，检查：

  • 策略收益是否存在自相关。
  • 买入持有收益是否存在自相关。
  • 超额收益是否存在自相关。
  • Alpha/Beta 回归残差是否存在自相关。
  • 收益序列是否平稳。
  • 是否存在波动聚集 / ARCH 效应。
  • 后续更适合研究 AR / ARIMA，还是 GARCH。

1. 时间序列是什么？

时间序列就是：

按时间顺序排列的数据。

在本项目里，典型时间序列是：

它和普通的一组数字不一样。

普通统计可能只关心这些数字的均值、标准差、分位数。

时间序列还要关心：

今天的收益和昨天、前几天、前几十天有没有关系？

2. 自相关：今天和过去有没有关系？

自相关的意思是：

当前值和自己过去值之间的相关性。

其中，因此被标准化到。

比如：

  • 今天涨，明天也更容易涨。
  • 今天跌，明天也更容易跌。
  • 前几天大波动以后，后面也容易大波动。

如果收益存在明显自相关，就说明序列不是完全随机散开的。

但要注意：

自相关不等于一定能赚钱。

因为信号可能很弱，也可能被交易成本、滑点、买卖延迟吃掉。

PACF 图应该怎么读？

读 PACF 图时，重点看：

  1. 哪些 lag 的柱子明显超出置信区间。
  2. 显著柱子是否在某个 lag 后整体消失。
  3. 后续柱子是随机围绕 0 波动，还是仍呈现系统性衰减或振荡。
  4. ACF 是否同时呈现符合 AR 模型的拖尾形状。

样本 PACF 不会像理论 PACF 那样整齐。即使真实 PACF 为 0，有限样本下也可能出现个别越过置信区间的柱子。因此 PACF 只能用于提出候选阶数，还要结合 AIC / BIC、Ljung-Box 和残差白噪声检验确认。

上面用“AR(k) 回归的最后一个系数”定义 PACF，这是回归（OLS）定义。项目实现用的是 statsmodels 的 Yule-Walker（modified，method="ywm"）估计量，它由样本自相关解 Yule-Walker 方程得到，与回归定义在大样本下近似等价，但有限样本的数值不完全相同。另外 statsmodels 要求 PACF 的最大 lag 小于样本量的一半，样本过短时高 lag 的 PACF 会返回空值。

截尾与拖尾：ACF / PACF 图怎么读？

时间序列教材里常说 ACF 或 PACF“截尾”或“拖尾”。这两个词描述的是相关系数随 lag 增加时呈现的形状。

截尾

截尾指的是：

在某个有限 lag 之后，理论上的相关系数全部为 0。

假设一个理论 ACF 在 lag后截尾：

图形上通常表现为：前几个 lag 有明显柱子，从 lag开始，大部分柱子落回 0 附近的置信区间内。

例如 MA(1) 的理论 ACF 只在 lag 1 可能非零：

因此称为“ACF 在 lag 1 后截尾”。

需要注意，样本 ACF / PACF 受随机误差影响，后面的柱子几乎不会精确等于 0。实际判断“截尾”通常是指：

  • 某个 lag 后不再出现连续、系统性的显著柱子。
  • 后续绝大多数柱子落在近似置信区间内。
  • 偶尔一根柱子越界，可能只是多次观察造成的随机假阳性。
拖尾

拖尾指的是：

相关系数不会在某个固定 lag 后突然变成 0，而是随着 lag 增加逐渐衰减。

典型形状包括：

  • 指数衰减。
  • 正负交替的阻尼振荡。
  • 缓慢趋近于 0。

只要，任意有限 lag 的通常都不严格等于 0，但会随增加逐渐衰减，因此称为“ACF 拖尾”。

若，ACF 通常同方向指数衰减；若，ACF 往往正负交替衰减。

为什么 AR() 的 PACF 会截尾？因为控制了前个直接滞后项以后，更远 lag 对当前值不再有额外直接解释力。

为什么 MA() 的 ACF 会截尾？因为当前值和超过期以前的值不再共享同一组白噪声冲击，所以理论协方差为 0。

不能只凭截尾机械定阶

ACF / PACF 的截尾和拖尾只是模型识别线索，不是最终结论。实际数据中还会受到以下因素影响：

  • 样本长度有限。
  • 参数接近 0，导致形状不清晰。
  • 季节性或结构变化。
  • 未处理的趋势和单位根。
  • 同时存在 AR 与 MA 项。
  • 一次查看很多 lag 带来的假阳性。

所以模型定阶还应结合 ADF / KPSS、AIC / BIC、Ljung-Box 和残差是否接近白噪声一起判断。

平稳性说的是：

一个序列的均值、方差等统计特征是否大致稳定。

弱平稳通常要求：

比如每日收益率通常比价格更接近平稳。

价格可能长期上涨或下跌，均值不断漂移。

但日收益率往往围绕 0 上下波动。

如果序列不平稳，很多时间序列模型会变得不可靠。

10. 单位根：为什么它麻烦？

单位根可以理解为：

序列受到冲击后，不太会回到稳定均值附近，而是可能长期漂移。

价格序列经常有单位根特征。

收益率序列通常更接近平稳。

如果拿不平稳序列直接做回归或预测，很容易出现“看起来显著、其实没意义”的结果。

这也是为什么时间序列建模前通常先检查平稳性。

11. 波动聚集：大波动容易接着大波动

金融市场里很常见的一种现象是：

平静的时候连续平静，剧烈的时候连续剧烈。

这叫波动聚集。

比如某个 ETF 今天大跌，明天不一定继续跌，但明天的波动幅度可能仍然比较大。

注意区别：

  • 自相关关注收益方向或收益数值本身有没有关系。
  • 波动聚集关注波动大小有没有关系。

大白话：

AR / ARIMA 更像研究“涨跌方向有没有记忆”，GARCH 更像研究“波动大小有没有记忆”。
