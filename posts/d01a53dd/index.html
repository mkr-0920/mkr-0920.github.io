CNS Ubuntu 22.04 搭建教程

本文档介绍如何在 Ubuntu 22.04 上使用 GitHub Release 的预编译 CNS（CuteBi Network Server）搭建 CLNC 的 UDP over TCP 中继服务，同时覆盖公网 IPv4、公网 IPv6 和双栈部署。

CNS 对外监听的是 TCP 端口。CLNC 将 UDP 数据包封装进 TCP/HTTP 隧道，CNS 解封后才向最终目标发送原生 UDP。

16. 常见问题

systemd 显示 active，但端口没有监听

检查：

常见原因是端口已被占用或 IPv6 地址不存在。

IPv4 局域网可用，公网不可用

检查：

  • 是否有真正公网 IPv4
  • 是否处于 CGNAT
  • 路由器 TCP 18080 映射是否指向正确内网主机
  • Ubuntu UFW 是否放行 TCP 18080

IPv6 局域网可用，外网不可用

检查：

  • DDNS AAAA 是否已更新
  • 光猫/路由器 IPv6 入站防火墙
  • UFW 的 IPV6=yes
  • 测试端网络是否本身具备 IPv6

TCP 端口可连接，UDP 测试失败

检查四组对应值：

同时检查服务器是否允许出站 UDP。

手机只有 IPv4，CNS 只有 IPv6

纯 IPv4 手机网络通常无法直接连接纯 IPv6 CNS。需要手机 APN 具备 IPv6/双栈，或改用具备公网 IPv4 的 CNS。
