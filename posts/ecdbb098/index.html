策略评估、显著性检验与 Alpha/Beta 归因

综合策略诊断表与最终分类

做完样本内/样本外测试之后，我们已经知道：

均线策略在样本外有没有跑赢买入并持有？

做完收益率分布分析之后，我们又知道：

均线策略有没有降低波动、改善 VaR/CVaR、减少尾部亏损？

但是实际决策时，不能只看其中一张表。

因为可能出现几种情况：

  • 策略收益更高，风险也不差。
  • 策略收益没赢，但最大回撤明显更浅。
  • 策略年化收益、回撤、夏普都不好，但每日收益分布确实更稳。
  • 策略收益和风险都没有改善。

核心字段可以这样理解：

字段含义怎么看
excess_annual_return策略年化收益 - 买入持有年化收益大于 0 说明收益增强
drawdown_improvement策略最大回撤 - 买入持有最大回撤大于 0 说明回撤更浅
sharpe_excess策略夏普 - 买入持有夏普大于 0 说明风险调整后收益更好
std_daily_return_diff策略日波动 - 买入持有日波动小于 0 说明日波动更低
var_95_loss_improvement买入持有 VaR95 亏损 - 策略 VaR95 亏损大于 0 说明 VaR95 改善
cvar_95_loss_improvement买入持有 CVaR95 亏损 - 策略 CVaR95 亏损大于 0 说明 CVaR95 改善
strategy_distribution_category只看分布维度得到的分类用来判断波动与尾部风险是否改善

这里有一个容易绕晕的地方：

最大回撤通常是负数，所以 drawdown_improvement 越大越好。

比如：

这说明策略把最大回撤从 20% 降到了 12%，是明显改善。

大白话：这些策略样本外年化收益都比买入持有低一点，但波动和尾部风险明显改善，属于“风控改善型”。

最终分类按优先级判断：

第一类：收益增强型

条件：

大白话：

策略样本外年化收益已经跑赢买入并持有。

这类策略最直接，因为它先解决了“有没有多赚钱”的问题。

第二类：风控改善型

条件：

大白话：

策略没有提高收益，但最大回撤更浅，或者夏普更好。

这类策略不一定适合追求最高收益的人。

但它可能适合更重视账户体验、回撤控制和风险调整后收益的人。

第三类：分布改善但绩效失败型

条件：

大白话：

从传统绩效指标看它失败了，但从每日收益分布看，它确实让波动或尾部亏损变小了。

这类策略要谨慎看。

它可能说明策略有一定“减震”效果，但减震代价太高，最终收益和整体绩效不划算。

第四类：完全失败型

条件：

大白话：

该赚的钱没赚到，该少亏的地方也没少亏。

这种策略通常没有继续投入研究资源的价值，除非你能解释它在特殊市场环境下还有别的用途。

总结一下：

但这个顺序不是绝对的投资建议。

它只是帮助我们把研究结果变得更清楚：

这个均线策略到底是在增强收益，还是在控制风险，还是只是表面变稳但绩效失败？

Alpha / Beta 回归：策略到底靠什么赚钱？

前面我们做了几层分析：

  • 样本外绩效：策略有没有跑赢买入并持有？
  • 收益率分布：策略有没有降低波动和尾部亏损？
  • 显著性检验：策略的超额收益是不是足够稳定？

但还有一个更细的问题：

如果策略表现变好了，它到底是因为真的有独立赚钱能力，还是只是少买了一点市场？

这就要用到 Alpha / Beta 回归。

这条公式可以先这样理解：

策略收益 = 跟着市场一起动的部分 + 市场解释不了的部分。

Alpha：独立收益能力

Alpha 可以理解成：

扣掉市场涨跌影响以后，策略自己额外贡献了多少收益。

如果一个策略的 Alpha 显著为正，说明：

即使考虑了买入并持有的涨跌，策略仍然有一部分独立收益来源。

这通常是量化研究最想看到的结果。

但要注意：

Alpha 为正，不等于 Alpha 显著为正。

比如：

这说明样本里看起来有 10% 的线性年化 Alpha。

但 p-value 很高，统计证据不够强。

大白话就是：

这 10% 可能只是样本里的随机运气，不足以说明策略真的有稳定独立收益。

Beta：市场暴露程度

Beta 可以理解成：

买入并持有涨跌 1%，策略大概跟着涨跌多少？

如果：

说明策略和买入并持有差不多敏感。

如果：

说明买入并持有涨跌 1%，策略平均只跟着涨跌 0.3% 左右。

这通常表示策略更防守。

如果：

说明策略比买入并持有更激进。

在均线策略里，Beta 小于 1 很常见。

原因很直观：

均线策略不是每天满仓，它会在某些时候空仓或降低暴露，所以自然不像买入并持有那样完整吃下市场涨跌。

所以如果一个策略改善了最大回撤，但 Beta 明显小于 1，就要问一句：

它是真的有 Alpha，还是只是少承担了市场风险？

R²：策略有多像买入并持有？

R² 可以理解成：

买入并持有的涨跌，能解释策略收益波动的多少比例？

定义：

如果模型完全不能比直接使用样本均值解释更多变化，会接近，于是接近 0。

如果：

说明策略收益波动有 80% 可以被买入并持有解释。

大白话：

这个策略很像基准，只是在基准上做了一点调整。

如果：

说明买入并持有只能解释策略收益波动的 10%。

大白话：

这个策略和基准的日常涨跌关系不强，可能有更多独立行为。

但注意：

R² 高不一定坏，R² 低也不一定好。

R² 只是告诉你“像不像基准”，不直接告诉你“赚不赚钱”。

Adjusted R²：调整后的 R²

Adjusted R² 是调整后的 R²。

它会考虑模型里解释变量的数量。

在变量很多的模型里，单纯 R² 可能会因为硬塞变量而变高。

Adjusted R² 会对此做一点惩罚。

Newey-West / HAC：更保守地看显著性

金融日收益有两个常见问题：

  • 自相关：今天的收益可能和昨天、前几天有关系。
  • 异方差：有些时期波动很大，有些时期波动很小。

普通 OLS 的标准误通常假设数据比较“干净”。

但金融市场很少这么干净。

所以项目里同时计算了 Newey-West / HAC 稳健标准误。

它不改变 Alpha 和 Beta 的点估计，但会用更稳健的方式计算：

Newey-West 只替换协方差矩阵估计：

$$
\operatorname{Var}{HAC}(\hat\beta)
=(X’X)^{-1}S{HAC}(X’X)^{-1}
$$

是最大滞后阶数，是 Bartlett 权重。它允许误差项在有限 lag 内自相关，并允许方差随时间变化。

当前均线策略更像一个风险暴露管理工具，而不是一个已经证明能稳定创造超额收益的 Alpha 策略。
